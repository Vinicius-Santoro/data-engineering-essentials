# Referências

Este guia privilegia intuição e prática. Para aprofundamento, as referências abaixo são fontes clássicas e/ou documentações primárias.

## Machine Learning geral

1. **James, G.; Witten, D.; Hastie, T.; Tibshirani, R.; Taylor, J.** *An Introduction to Statistical Learning: with Applications in Python*. Springer, 2023. DOI: 10.1007/978-3-031-38747-0.
2. **Hastie, T.; Tibshirani, R.; Friedman, J.** *The Elements of Statistical Learning: Data Mining, Inference, and Prediction*. 2nd ed. Springer, 2009. DOI: 10.1007/978-0-387-84858-7.
3. **Bishop, C. M.** *Pattern Recognition and Machine Learning*. Springer, 2006.
4. **Murphy, K. P.** *Probabilistic Machine Learning: An Introduction*. MIT Press, 2022.
5. **Kuhn, M.; Johnson, K.** *Applied Predictive Modeling*. Springer, 2013. DOI: 10.1007/978-1-4614-6849-3.
6. **Géron, A.** *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow*. 3rd ed. O'Reilly, 2022.
7. **scikit-learn developers.** *scikit-learn User Guide*. Documentação oficial do projeto.

## Árvores, ensembles e boosting

8. **Breiman, L.** Random Forests. *Machine Learning*, 45, 5–32, 2001. DOI: 10.1023/A:1010933404324.
9. **Breiman, L.; Friedman, J.; Olshen, R.; Stone, C.** *Classification and Regression Trees*. Wadsworth, 1984.
10. **Friedman, J. H.** Greedy Function Approximation: A Gradient Boosting Machine. *The Annals of Statistics*, 29(5), 1189–1232, 2001. DOI: 10.1214/aos/1013203451.

## Support Vector Machines

11. **Cortes, C.; Vapnik, V.** Support-vector networks. *Machine Learning*, 20, 273–297, 1995. DOI: 10.1007/BF00994018.

## Avaliação, validação e leakage

12. **Kohavi, R.** A Study of Cross-Validation and Bootstrap for Accuracy Estimation and Model Selection. *Proceedings of IJCAI*, 1995.
13. **Varma, S.; Simon, R.** Bias in error estimation when using cross-validation for model selection. *BMC Bioinformatics*, 7, 91, 2006. DOI: 10.1186/1471-2105-7-91.
14. **Saito, T.; Rehmsmeier, M.** The Precision-Recall Plot Is More Informative than the ROC Plot When Evaluating Binary Classifiers on Imbalanced Datasets. *PLOS ONE*, 10(3), e0118432, 2015. DOI: 10.1371/journal.pone.0118432.
15. **Brier, G. W.** Verification of forecasts expressed in terms of probability. *Monthly Weather Review*, 78(1), 1–3, 1950.

## Interpretabilidade

## Clustering e redução de dimensionalidade

19. **Ester, M.; Kriegel, H.-P.; Sander, J.; Xu, X.** A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases with Noise. *KDD*, 1996.

21. **van der Maaten, L.; Hinton, G.** Visualizing Data using t-SNE. *Journal of Machine Learning Research*, 9, 2579–2605, 2008.

## Como aprofundar sem se perder

Para uma segunda camada depois deste guia:

- **ISLP** para uma sequência didática moderna de ML estatístico;
- **Elements of Statistical Learning** para maior profundidade matemática;
- **Forecasting: Principles and Practice** para séries temporais;
- **Sutton & Barto** para RL;
- **Hernán & Robins** para causalidade;
- documentação oficial do **scikit-learn** para APIs e detalhes atualizados.

!!! note "Documentação de software muda"
    Assinaturas e defaults de bibliotecas podem mudar entre versões. Use este material para os conceitos e confirme detalhes de API na documentação da versão instalada quando necessário.
